# Python Amazon Prime TV Shows and Movies - EDA Project
An exploratory data analysis project on the Amazon Prime TV Shows and Movies dataset using Python, Pandas, NumPy, Matplotlib, and Seaborn.
The project focuses on cleaning and exploring the dataset, identifying trends in content, analyzing genres and ratings, and creating visualizations to uncover meaningful insights.
Project: https://colab.research.google.com/drive/1q3tKIEP9hrt3BXPU0lpgccxF9E2JfTFn?usp=sharing

Tools & Libraries: 

Python | Pandas | NumPy | Matplotlib | Seaborn

🔍 Key Analysis
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Genre and rating analysis
Content distribution and trends
Data visualization and insights

Goal: Turn raw entertainment data into clear, data-driven insights through Python-based analysis.
